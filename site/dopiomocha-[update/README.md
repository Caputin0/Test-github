# Doppio Mocha

Projeto acadêmico de uma cafeteria virtual desenvolvido com PHP, MySQL, HTML, CSS e JavaScript.

## Executar
1. Tenha PHP 8.1+ e MySQL instalados.
2. Execute `site/database/doppio_mocha.sql` no MySQL.
3. Ajuste as credenciais em `site/config/conexao.php`.
4. No terminal, entre na pasta `site` e execute `php -S localhost:8000`.
5. Acesse `http://localhost:8000/html/index.php`.

Não é necessário XAMPP. O PHP executa a aplicação e o MySQL armazena os dados.

Consulte `site/README.md` e `site/docs/` para instruções, requisitos, banco de dados e manual.
